# ADS Fatec — Exercises

Repository containing programming exercises, assignments, and materials developed throughout my **Systems Analysis and Development** degree at **Fatec Ribeirão Preto**.

Although the repository is predominantly documented in English, most of the code and academic work are currently written in Brazilian Portuguese, as it is the language used at the institution.

## Sobre o repositório (🇧🇷 Brazilian Portuguese)

Este repositório contém exercícios de programação, trabalhos e materiais desenvolvidos ao longo do meu curso de **Análise e Desenvolvimento de Sistemas** na **Fatec Ribeirão Preto**.

Apesar da documentação do repositório ser majoritariamente em inglês, a maior parte dos códigos e trabalhos está atualmente em português brasileiro, que é o idioma utilizado na instituição.

## Contents

### [C](./C)

Exercises developed for the **Programming Languages** course, covering fundamental programming concepts.

### [C++](./C++)

Exercises developed for my first programming course, focusing on **algorithms, problem solving, and programming fundamentals**.

### [C#](./C#)

Exercises from the **Object-Oriented Programming** course, covering concepts such as classes, objects, encapsulation, inheritance, and other OOP principles.

### [Flutter - Dart](./Flutter-Dart)

Activities developed for the **Mobile Device Programming** course, exploring mobile application development with the Flutter framework and Dart programming language.

### [VBA](./VBA)

Exercises from the **Microinformatics Programming** course, focused on automation and programming with VBA.

### [Diagrams](./Diagrams)

Diagrams and modeling activities developed throughout the course, including **UML diagrams** for Software Engineering and Object-Oriented Programming, as well as **ER diagrams** for Database Systems.

### [SQL](./SQL)

Database assignments and projects developed for the **Database Systems** course, including **MySQL Workbench models (`.mwb`)** and **SQL scripts (`.scripts`)**.
