# ADS Fatec — Exercises

Repository containing programming exercises, assignments and materials developed throughout my **Systems Analysis and Development** degree at **Fatec Ribeirão Preto**.

Despite the description being predominantly in English, all the code and work developed are currently largely adapted for Brazilian Portuguese, as it's the language spoken at the institution.

## Sobre o repositório (🇧🇷 Brazilian Portuguese)

Este repositório contem exercícios de programação, trabalhos e materiais desenvolvidos ao longo do meu curso de **Análise e Desenvolvimento de Sistemas**, na **Fatec Ribeirão Preto**.

Apesar da descrição majoritáriamente em inglês, atualmente, todos os códigos e trabalhos desenvolvidos estão em sua maior parte adequados ao português brasileiro, já que é a língua falada na instituição.
